# Portfolio site

Static personal portfolio site built with plain HTML, CSS and JavaScript.

## Built with
- HTML5, CSS3 (glassmorphism UI, responsive layout), vanilla JavaScript (scroll animations)
- Google Fonts (Inter), Font Awesome icons

## Run locally
```bash
git clone https://github.com/SMKehTDOG2335/portfolio.git
cd portfolio
python -m http.server 8000   # or just open index.html
```
